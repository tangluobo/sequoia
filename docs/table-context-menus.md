# 打开表的右键菜单

本轮对应 Java `TableDataView.setupRowContextMenu`、`TableCellContextMenuUtils`、`FrozenRowSelectorPane` 和 `RowSelectorDragSelection`。只讨论“打开表”数据页，查询结果使用其原有独立控制器；全项目迁移状态仍见 [迁移清单](migration.md)。

## 选区与菜单

行选择器与数据单元格共用一套菜单，顺序为：设置为空字符串、设置为 NULL、分隔线、删除 记录、复制、复制为、粘贴、保存数据为...、分隔线、排序、筛选、移除全部排序及筛选、分隔线、显示、刷新。无主键、只读、无数据选区和剪贴板无文本时保留相应项目并禁用，按原版条件处理。

- 右键已选中的行或单元格保留多选；右键未选中的目标切换到该行或该单元格。行选择器支持普通、Ctrl、Shift 与拖动范围选择；Ctrl 点击部分选中的行会清除整行，不生成互补单元格选区。
- 行选择标记、行范围锚点和焦点列分开保存：整行与单元格混合 Ctrl 选择后，仍有行选择器标记则使用插入行粘贴；只有单元格选区则从选区左上角覆盖，超出现有行时追加新行。插入行在焦点行之后显示，原有物理行身份与未保存修改不会因排序而错位。
- 设置空字符串/NULL 作用于选中的可编辑数据单元格，继续通过原保存流程写入数据库。复制保留 Java 的稀疏选区布局和 NULL/空字符串区别。
- “复制为”接入 Insert、Update、JSON 原字段/驼峰、注释：值及三种 TSV。Update 使用原表的主键与选中字段；注释从 MySQL/PostgreSQL 字段元数据载入，SQLite 或无注释字段按字段名回退。
- “保存数据为...”使用原生 TSV 文件对话框，导出当前可见页的全部行而非仅选区，经共享 WriteText 命令实际写盘；取消对话框不写文件。
- “删除 记录”确认后立即调用独立删除命令；未保存的新行只在本地移除。数据库返回后按匹配的原行移除并重映射行索引，保留其他行的未保存修改和新增草稿；失败不当作已删除。沿用现有数据库安全写入校验。
- 排序/筛选在当前页本地执行，支持多列排序、六种按值筛选、自定义条件和移除。显示子菜单可恢复隐藏列，很多列时按可见项绘制并滚动；鼠标和键盘导航跳过隐藏列。刷新继续使用原有脏数据确认流程。
- 空白数据区及空表仍可打开菜单；表头保留独立的正序排列、倒序排列、取消排序菜单，表头填充区不弹数据菜单。

## 原版画面基准

`crates/core/tests/java/TableMenuOracle.java` 在独立 JavaFX 场景中加载原 `TableDataView`，在首次异步查询执行前阻止加载，并注入合成页。对可见行选择器和数据单元格发送 JavaFX 输入事件，只打开菜单，不执行数据库或剪贴板写入。原 Java 文件不修改。

三种原版快照位于 `target/table-menu-oracle-368/`。原版菜单为 System Regular 10px、普通行高 20px、分隔线 3px，菜单本体 114×255；快照 138×279 还包括 JavaFX 阴影。可见行选择器与数据表的零宽度逻辑选择器必须区分；最初误命中逻辑列的夹具已修正，不作为最终选区/禁用状态基准。

Rust 使用仅对打开表菜单生效的字体/行高/边距，方角、边框和阴影；排序/筛选子菜单重用原 Java SVG 路径及颜色。禁用项按原版透明度处理，避免把已经变灰的文字再次淡化。渲染器字体栅格化与原生窗口边界仍不能据此宣称逐像素完全相同。

## 内存与资源

排序筛选与插入顺序保存行索引，不复制整页字符串。选区保留位图与行选择标记；列菜单按可见项绘制。复制/导出上限 8 MiB，粘贴文本上限 8 MiB、暂存估算上限 16 MiB，每次新增行不超过 1000。列注释上限 256 KiB。删除请求纳入队列字节预算，服务端将行内容移入删除计划并原样移回响应，不再额外克隆一份完整行。会话、对话框文本资源和图标随所属上下文释放。

## 验收范围

实际 egui 输入测试覆盖单选/多选右键、未选中目标切换、嵌套复制菜单、批量设 NULL、粘贴、排序、筛选、隐藏列、只读与空白区。临时 SQLite 验证菜单粘贴→工具栏保存→确认后立即删除→其他草稿保留→导出文件写入。

原生 Rust 夹具使用 egui 输入钩子给自己的隔离窗口输入鼠标事件，并记录实际选区与菜单几何。不会自动操控用户窗口，不读取剪贴板正文，不访问保存的数据库连接。最新完整检查、原生成品与验收路径在完成构建后记录在对应 `build-info.json`。
