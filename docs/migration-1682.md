# Java 操作链继续复核（1682，本轮成品检查完成）

本轮继续以原 Java 的真实组件、事件和命令为依据补齐实现，原项目保持只读。沿用原加密配置，不将按钮注册、静态模型或测试服务端等同于全部实机验收。

## SSH 存储页

原 `ssh/StoragePanel.java` 同时提供块设备表和 LVM 树。此前 Rust 的 LVM 标签没有持久选择状态，工具栏无法取得所选 PV/LV；挂载的文件系统和 fstab 开关也只是普通字符串输入。

现在为该页接入独立控制器和布局，恢复顶部工具栏、七列块设备表、固定 220px 的 LVM 树、提示和底部状态；表格空白区域继续显示原版条纹和单线网格。原 Java 组件从原源码在独立目录编译，用只返回测试数据的执行器刷新，取得节点快照和布局测量，未执行磁盘命令。LVM 行高按实际组件的 21px 对齐。

表头可按原版顺序在升序、降序和原顺序之间切换，拖动分隔线可调整列宽，由末列补偿宽度，保持行高和排序状态不变。排序仅缓存行号映射，点击、键盘移动和回车打开都映射回实际设备；表格和 LVM 树支持方向键、Home/End，树支持左右展开折叠和回车打开。LVM 节点的选择会用于 VG/LV 表单预填；块设备双击依设备状态打开初始化或挂载表单。

完整操作链包括初始化 PV、创建或扩展 VG、扩展 LV、格式化或仅挂载。输入先校验，再显示实际命令和确认；取消不入队，执行中禁止重复提交，成功后经同一 SSH actor 重新读取并更新设备与 LVM 信息。远端拒绝写入时显示可复制的错误弹窗，不伪造成功。后台状态仍由共享服务层管理，视图不执行网络 I/O。

挂载恢复“不格式化/ext4/xfs”下拉框和“写入 /etc/fstab”复选框，默认不格式化、默认写入 fstab。修复包含空格、制表符或反斜杠的目录持久化记录；挂载目标仍用原路径，写入记录使用 fstab 转义。格式依据见 [fstab(5)](https://man7.org/linux/man-pages/man5/fstab.5.html) 和 [getmntent(3)](https://man7.org/linux/man-pages/man3/getmntent.3.html)。

LVM 文本仅在收到清单回复时解析；页面释放原始明细文本，只缓存树节点、显示文本与排序行号。表格和树按可见行绘制，空白网格按视口绘制，不为每个空单元格构造控件。

管理表单和确认框不再为取得文件默认路径而初始化隐藏的文件面板，避免存储、容器和端口管理操作意外触发 SFTP 清单请求。原生存储流程额外断言没有创建无关文件面板。

## SSH 列表和连接树

Docker 表格右键菜单对齐原版 `DockerPanel.updateMenuState`：有 Exited 项才可启动，有 Up 项才可停止；运行中项目不可普通删除，多选禁用单项日志等操作，数量显示为“(N个)”。菜单使用统一 23px 行高和原有分隔位置；后台操作中禁止重复发送操作。端口和容器列表恢复左侧行选择器的按下拖选，端口筛选后按可见行而非原始行号选取范围；右键保留已有多选，Ctrl 切换单行，Shift 按可见范围选择，点击空白处清除选择。短列表至少保留原 Java 的 80px 表格高度。管理表格列分隔线可拖动，列宽由相邻列补偿，行高固定 24px。

独立端口页恢复固定的标题栏、协议筛选栏、表头及 18px 状态栏，表格占满中间区域并使用内部纵向滚动，不再由外层面板把整页一起滚走。默认列宽按 Java 的 60/140/80/70/180 分配后约束在可见宽度内；空白区域保持白色，只绘制有数据的单线网格。原始 PortPanel 在独立目录从原源码编译，通过只含自有数据的列表取得组件快照和几何；没有创建 SSH 会话。

原生截图复核发现筛选栏比 Java 高 10px：egui 横向布局在子控件修改高度前已经分配了行高。现在先设置行高再创建横向布局，正式窗口检查额外断言表头相对内容区起点为 53px。状态栏使用原版“共 N 个监听端口（总计 M）”；协议切换清除旧选择和范围锚点，避免保留筛选前的隐藏行选择。

设备表额外测量了原 Java 在 896px、700px 组件宽度下的七列边界，测试向量分别为 `[175,79,105,85,105,194,135]`、`[136,62,81,65,81,152,105]`。缩窄时按各列超过最小宽度的比例收缩，并把累积边界对齐到物理像素，避免末列溢出与分隔线落在小数像素上。管理表同样保留最小列宽与手动调整后的约束；存储表和端口页均有实际 egui 窄视口检查。

连接树在开始密码检查前合并同一主机的在途请求，修复首次连接正在认证时再次点击导致重复密码提示。临时密码只用于同一连接公开参数；修改端口等参数后不复用旧密码。未勾选保存不会写回原配置。

原 Java 系统设置中的“开机自动启动”“自动检查更新”仅创建静态控件，没有后台调用或保存处理。这类参考边界单独记录，不将其包装成已实现的系统功能。
