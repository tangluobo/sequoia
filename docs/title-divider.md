# 标题栏与内容页分隔线

原 Java `tomato-view.fxml` 的标题栏为固定 52px，底边使用 `#D9D9D7` 的 1px 内边框。Rust 原来在标题栏的 `bottom()` 位置画居中描边，像素对齐后落入下一块内容；标签栏背景随后覆盖了这条线。原优化版 nav-icons-357 的真实截图中，右侧 `(500,52)` 为白色，下一行已经是标签背景，复现用户报告。

修复统一使用标题栏内部最后 1px 的填充带，并将裁剪限制在标题栏内；左侧搜索区同步处理。标题栏仍为 52px，不增加标签间距、不移动内容，也不将线画到弹窗上层。导航彩色 SVG、Windows exe 图标、旧配置、会话与协议实现不变，无新增纹理、后台任务或定时刷新。

开发版连接页和工具页截图已与 nav-icons-357 比较：左右两段分隔线横向完整可见，变化仅在旧/新分隔线所在两行像素内，其他像素相同。脚本为 `scripts/qa/compare-header.py`，证据为 `target/window-probes/header-dev-358/header-proof.json`。

回归测试对真实 UI 输出的三角网格按绘制次序、透明度和裁剪进行采样，检查空白页、打开两个标签、切换、清空标签和隐藏侧栏的边框颜色。DPI 测试使用 1、1.25、1.5、2 倍无窗口渲染；它不等同于实际 Windows 显示器之间移动窗口的验收。

格式、严格 Clippy、全目标开发构建、实际 Cargo 优化构建、407 项默认测试和 CLI 自检通过，62 项条件测试默认忽略；旧配置只读检查仍为 59 个连接、5 个分组。优化成品为 `target/qa-release-header-divider-358/release/tomato.exe`，SHA-256 为 `11BF2EF009CC48A713C24140218F74D91395009B7E6101BDF26A2645E319BFC3`，完整证据见同目录 `build-info.json`。

成品的六种布局截图与 357 对比通过：变化仅在底线所在的第 52、53 行。连接选择弹窗覆盖的区域保持不变，露出的标题栏底线正常显示，避免把底线强制画到弹窗前面。四种普通、选中、溢出、下拉菜单标签窗口中，左右标题底线均逐像素检查可见；原 Java 标签的几何、底色、边框及文字边界回归保持原结论，长标题仍有约 1px 度量差异，不宣称全应用逐像素一致。证据分别为 `target/window-probes/header-release-358/header-proof.json` 和 `target/window-probes/header-tabs-release-358/geometry.json`。
