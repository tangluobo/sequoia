- 数据库标签接通“表格配置”“刷新结构”“刷新数据”，包括只读结构页和未保存编辑保护。表格字体使用旧 `tableFontName`、`tableFontSize` 字段，保留未知字段与保存冲突保护，取消不写文件。450×96 配置窗口对照隔离 JavaFX 原组件；字体列表从字段正下方打开独立窗口，完整选择列表不受父窗口裁剪。只保留当前共享字体资源，替换后释放旧字节，行高、绘制和命中使用相同字号。
- Kafka/RocketMQ 接通 Ctrl/Command、Shift、多选右键、批量确认与取消。后台复用协议客户端和 SSH 路由，逐组删除，限制数量和时间，失败后继续后续组，汇总成功与失败并刷新。实际 Kafka/RocketMQ 服务验证与合成行的界面截图分别记录。
- Hive 补齐连接树、懒加载库、查询连接/库选择、保存查询作用域、设计表打开、SQL 预览、保存、相关数据页刷新及断开。库切换保留旧认证、HTTP/TLS 参数后缀，NoSASL 等模式不因没有密码反复弹窗。更正 1672 文档中将后端接入当作界面已完整接通的描述。

## 退出和资源释放

正式窗口检查发现原任务队列缺少完整的协议关闭流程。现在任务路由、会话执行和监督分别放在 `tasks/queue/routing.rs`、`actor.rs` 和队列本身，采用一个共享关闭信号，无额外常驻线程。

退出时立即拒绝新任务，取消正在等待或交付结果的任务，在后台释放结果缓存与排队载荷，各会话并行执行原有断开用例，关闭 SQL、SSH 和 Mongo 会话。每个会话的关闭宽限为 2 秒；文件/ADB、RDP 和证书回滚继续使用原来的绝对时间预算，窗口仍能绘制和处理关闭事件。强制退出保留尽力释放的兜底。

新增行为检查覆盖结果通道已满、真实 MySQL TCP 握手卡住、关闭信号早于调度器首次执行及重复关闭。隔离 HS2 工作流覆盖一次 DDL 保存、数据页刷新、查询结果/计划/状态、显式断开，再重新连接并通过应用退出控制器关闭，检查两次 CloseSession。正式 EXE 的窗口捕获也改为经过同一个退出控制器，单纯结束进程不能替代此验证。
