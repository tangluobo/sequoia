# SSH 字体下拉框

原实现只对齐了弹层锚点，没有建立菜单内容的最小宽度，也没有关闭文字自动换行；表单的较大行高和间距还会被菜单继承。长字体名因此可能逐个字符折行。

对照只读 Java `ConnectModule.java` 的 SSH 全局设置页：字体控件为可编辑 ComboBox，首选宽度 220。Rust 保留可编辑输入、字体预览及原 `global.json` 保存流程，菜单以输入框和箭头的整体边界为锚点，从正下方左对齐展开；内容宽度至少与控件相同，文字保持单行，较长名称按内容展开。候选行使用 22 个逻辑像素，列表最大高度 200，超出后垂直滚动。没有修改全局字体、其他菜单或表单行高。

原生开发验收 `target/window-probes/ssh-font-dev-1327` 使用真实窗口和自有 loopback SSH，从标签右键“全局配置”进入并点击字体箭头。六个已安装字体全部在菜单中单行显示，包括 Cascadia Code、Cascadia Mono、Consolas、Courier New、Lucida Console、Monotype Corsiva；菜单边界与输入框一致。额外 125%、150%、200% 的实际 UI 离屏渲染和字形行数检查通过，证据在 `target/window-probes/ssh-font-dpi-1331`。这些缩放检查未修改 Windows 显示设置，也不代表物理显示器输入测试。

生产源代码冻结 `ssh-font-1328`，2201 个文件。与 1315 相比，生产修改仅包括设置页和明确启用的截图夹具；未增加配置字段、网络连接或后台轮询。539 项既有默认回归通过，77 项按原环境条件忽略；严格 Clippy、全目标构建、格式及 CLI 自检通过。
