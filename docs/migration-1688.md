# 继续对照 Java 迁移（1688）

连接导入已接通文件读取、独立勾选、重复分析、引用重映射、加密保存、失败及成功弹窗。主界面和 CLI 使用同一业务处理器。原 Java 项目只读，旧配置继续直接读取，无格式迁移。

## 已实现的完整流程

- 原导入窗口 580×500、30 像素行高、原图标、按钮位置及默认未勾选重复项；目录勾选彼此独立。父目录不在文件中的项目仍展示为根行。重复或空 ID 使用导入序号作界面身份，各项可分别选择，保存时生成新 ID。
- 与原 Java 首个同 ID 匹配规则一致；重映射目录及 SSH 跳板。未选择的重复目标可复用现有连接，失效引用清除；重复名称追加序号，未知字段与选中的凭据保留。
- 导入、导出共用树导航及默认 Modena 勾选图形：图标点击勾选、名称点击选择、双击展开或折叠；方向键、Home/End/Page 与滚动定位接通。空格遵循原 TreeView，仅选择行，不切换勾选。导出目录保留递归及半选，导入目录保持独立。
- 文件读取、解析、加密和提交移到后台；导入文件及保留模型分别限制为 32 MiB，最多 50,000 项，绘制仅遍历可见行。目录构建和验证采用迭代方式，5,000 层目录用例通过。
- 提交同时核对预览源文件、工作区模型和磁盘配置版本；取消或失败不发布部分主文件。提交前再次检查外部修改，原配置先加密备份。取消和提交交错时仍接收已提交结果，避免内存与磁盘不同步；保存后可以继续编辑。
- 配置版本快照改为 SHA-256 摘要，不长期保留一份完整加密文件；后台只返回新增连接，草稿通过 Arc 共享。中文标题使用已有按需粗体加载器和 YaHei UI 字面，多个字族、DPI 缓存共享同一字体字节；空闲启动不额外加载粗体 CJK。

## 验证与边界

940 项工作区测试通过、0 失败、96 项条件忽略，64 个套件；格式、严格全目标 Clippy、正式优化 CLI 自检通过。4 份旧配置只读检查及 283 份 Java 源文件未修改检查通过。真实 MySQL/PostgreSQL 的 24 项后端及原生控件工作流完成回归，未连接保存的主机。

原 JavaFX 实际事件验证导入/导出鼠标和键盘语义；正式 CLI 的四种导入结果再由原 Java ConnectionImportPlanner、SecurityUtils 和 Gson 逐项核对，覆盖默认去重、手动重复、重复/空 ID 与未选首个 ID。只使用合成配置及虚构凭据，未落盘 Java 解密结果。导出加密互通也已重新执行。

同一正式 EXE 的导入默认态及导出空选、半选三个原生窗口帧均逐张查看，并与对应原 Java 窗口对照。标题粗体及默认勾选图形已修正；不据此声明全应用像素完全相同或 Windows 文件选择器的人工输入验收。安装器完成构建、解包及三项二进制比对，未执行安装。
