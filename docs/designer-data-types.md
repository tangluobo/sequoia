# 表设计器数据类型交互

对照原 `TableStructureView.java` 的 `DataTypeComboBoxTableCell` 和 `connect-tree.css`：按下类型单元格即清除其他选择、选中当前单元格并进入编辑，自动展开下拉；不再要求先双击，再点击箭头。当前类型获得候选焦点并滚入列表视野。

上下键仅移动候选高亮，不修改字段或标记脏状态；回车及鼠标选择才提交。点击编辑文字后可以输入，按去除首尾空格、不区分大小写的包含关系筛选。Escape 丢弃本次编辑；点击其他位置提交输入。重新打开恢复完整类型列表和当前类型焦点。字段修改仍进入既有草稿、SQL 预览和保存流程。标签的未保存判断比较实际编辑值，单纯打开或浏览候选不会产生未保存提示；尚未提交的实际文字改动仍受保护。

下拉层覆盖网格时阻止底层范围选择和单元格点击；关闭编辑器、切页、释放设计器时关闭其下拉并释放编辑状态。候选类型复用静态元数据，仅活动编辑器分配一份短状态和筛选文字，列表和字段网格均按可见行绘制。

按用户补充要求，类型及属性下拉均锚定整个编辑框的正下方，左边缘对齐；关闭自动向右翻转的备选定位。下方空间不足时缩短列表并滚动，避免横向偏移。长类型名称按实际文字宽度计算下拉宽度，并受窗口剩余宽度限制。

原 Java 隔离窗口验证使用原类、原 CSS、内存 JDBC 元数据和 JavaFX 事件，不读写用户配置、不连接保存的服务器、不注入系统输入。原版实测下拉宽 135px、高 505px、20 个可见候选、候选行高 25px；当前 Rust 按这些尺寸、原高亮颜色和悬停箭头绘制，编辑文字垂直居中。证据在 `target/type-picker-java-1026`，源码和 CSS 与原有编译参考哈希一致。

实际 egui 控件回归覆盖单次按下、当前项滚动、筛选、鼠标选择防穿透、上下键、回车、Escape、重新打开、失焦提交以及进入 SQL 预览。`scripts/qa/designer-types.ps1` 通过独立配置的原生窗口执行六种状态并检查帧缓冲与状态证明。字形光栅、滚动条皮肤和越出窗口边缘的浮层实现仍有框架差异，不声称全部像素一致。
