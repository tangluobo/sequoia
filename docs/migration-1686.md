# 1686：连接选择导出、加密互通与滚动交互

原生实现与本轮检查完成，整个应用的迁移/实机/视觉验收仍未标记全部完成。

## 对照原 Java

对照 `ExportConnectionDialog.java` 和 `ConnectModule.handleExportConnections`：原版先显示选择树，默认不勾选连接、不包含密码，文件夹复选框联动子项，部分选择保留半选父目录，确认后生成带格式与版本的加密文件。此前 Rust 界面只直接导出全部连接的脱敏 JSON，本轮补齐原窗口及完整生成链路。原 Java 六份相关源文件在独立目录编译，实际 JavaFX 控件捕获空选和半选两个 500×450 状态，并验证半选父目录保留与默认密码选项，另用原 Java 真实 TreeView 核对 LEFT/RIGHT/DOWN/END/HOME。

窗口采用相同标题、原图标、30px 行、目录展开/折叠与复选框、全选/取消全选、包含密码、取消/导出、警告与完成提示；补齐方向键父子/相邻节点导航、Home/End、PageUp/PageDown 和屏幕外目标自动滚动，保留空格勾选及底部按钮焦点隔离；校准树与底部按钮位置，并检查原生 GPU 截图中的左对齐。目录勾选联动，空目录可独立选择，半选父目录进入导出；未选兄弟连接不会导出。列表虚拟化，选择模型只持有 ID，不每帧复制密码和连接内容。

## 生成、取消与保护

- GUI 与无界面入口共用 `Command::ConnectionExport`，由后台执行编码及磁盘写入；窗口用阶段枚举与队列任务 ID 关联，拒绝重复提交，忽略旧窗口结果，关闭窗口或应用时取消所属任务。
- GUI 文件使用原版 `TOMATO_ENCRYPTED` 标记和 AES/base64，解密后为 `tomato-connections-export` / version 1 / connections 封装。默认递归去除敏感字段，明确勾选后才包含；未知配置字段、ID、目录及跳板引用按选中范围保留。CLI 原有 `export` 子命令保留既有脱敏输出，新链路可通过共享 CommandHandler 调用。
- JSON 写入有界并检查取消，限制完整加密文件不超过导入支持的 32 MiB。磁盘写入使用同目录临时文件、分块取消检查、同步及提交前再次检查；取消或失败不发布半成品。当前连接文件的实际路径/别名不能作为导出目标，不改写源配置或创建原配置备份。
- 测试实际写出加密文件并重新导入，核对密码策略、目录与跳板重新映射、未知字段、重复提交及失败草稿。原 Java `SecurityUtils` 与 Gson `ConnectionConfig` 还分别读取同一份正式 CLI 生成的脱敏/含密码文件；只使用虚构凭据，解密内容留在内存，没有落盘或输出实际凭据。
- RocketMQ 的原有 MsgId 查询后端保持，界面页签、标签及输入提示改回原 Java 的文字。

## 文件列视图与设计器下拉

新增真实控件键盘用例发现：导出树的 Home 改变了选择，却没恢复到顶部。根因是读取滚动状态时漏掉 ScrollArea 内部存储盐值的一层转换，导致总是读到默认偏移。核对全部滚动状态读取点后，同步修正文件列视图和设计器字段类型下拉；没有修改第三方库或滚动策略。文件列视图在滚动后从空白区拖动框选时，选中的文件现在与屏幕上实际显示的行一致；列视图边缘自动滚动使用正确起点。字段类型下拉在上下切换仍然可见的候选项时保持位置，不把候选项反复推到下方。三个行为均通过实际 egui 输入与绘制结果检查；没有把这些测试称为资源管理器物理拖放或新的完整 Java 像素验收。
