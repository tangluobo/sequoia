# ADB 网络连接

Tomato 通过内置的 Rust ADB 客户端连接设备的 TCP 调试端口。H.264 视频经设备本地套接字传输，并使用随 Tomato 提供的 scrcpy 服务。稳定截图和控制复用同一 ADB 传输。标签页的「独立窗口」和窗口里的「返回标签」复用同一会话。

## Android 11 及更新版本的无线调试

1. 在 Android 的开发者选项里打开「无线调试」，记录主页面显示的设备地址和连接端口。
2. 首次连接时，在设备上打开「使用配对码配对设备」。在 Tomato 的 ADB 连接编辑器中展开「无线配对」，输入该弹窗显示的配对地址和六位配对码，点击「配对」。
3. 配对成功后，在连接的「主机」和「端口」中填写 Android 无线调试主页面的信息，保存并打开连接。重新打开设备无线调试后，以主页面显示的新端口为准。

传统 ADB 网络调试可使用设备已经启用的 TCP 端口，常见端口为 5555。设备提出 RSA 授权时，在设备上确认。Tomato 可读取原有 `~/.android/adbkey`，或在 Tomato 数据目录生成密钥。显式设置 `TOMATO_DATA_DIR` 的隔离配置使用自己的密钥。

连接文件和全局配置中的 `adbExecutablePath` 作为旧字段保留。Tomato 在连接和重连时统一使用内置客户端。USB 直连和设备自动发现尚未接入。

隔离测试覆盖原生 ADB 授权、H.264 与 PNG、屏幕控制、共享会话和重新连接。Android 实机配对与视频效果仍待验收。
