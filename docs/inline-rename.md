# 文件和数据库对象原位重命名

对照只读 Java `AbstractFileBrowserPane` 的三种视图及 `TableObjectsView` 实现：

- S3、阿里云 OSS、FTP、SFTP、SSH 文件面板和本地文件面板共用原位编辑。首次单击选择，已单独选中的项目再次单击后延迟 300 ms 编辑名称；双击继续打开，Ctrl/Shift 多选不启动改名。
- F2、右键“重命名”和再次单击进入同一个输入框。Enter 或失去焦点提交，Escape 取消；未修改、空名称不发请求。文件名不能包含路径分隔符，Bucket 不提供改名。
- 详情列表保留图标和固定行高，缩略图名称框覆盖在原名称位置，列视图以完整路径定位项目，可以改名已展开的上级目录。成功后返回有效的父目录刷新，失败保留原路径并显示后台错误。
- 数据库对象页的表和视图均支持相同的再次单击、F2 和右键入口；编辑不改变图标、行高和选择布局。提交仍经过数据库对象命令、方言适配器和已有标签刷新流程。

编辑状态每个面板最多一份，只在编辑期间保留名称；撤销历史上限 128 KiB。结束编辑、切换目录或关闭标签后释放文字状态。300 ms 等待使用一次延时重绘，不增加空闲轮询线程。普通帧不再为了并未触发的文件操作复制全部已选中条目。

验证包括实际 egui 控件的指针/键盘事件、真实本地文件 actor，以及独立回环 S3 HTTP 服务的 CopyObject、删除、重新列举、目录前缀改名及拒绝请求。原生窗口截图使用隔离 S3 配置，由窗口自身注入 egui 事件，不向操作系统发送鼠标事件；这不等同于真人操作或逐像素 Java 对比。FTP/SFTP 的本次覆盖为共用界面交互回归，未连接用户保存的服务器。

原有连接配置直接读取；本次功能不修改连接格式，不写入用户的旧配置。运行时协议实现没有移入视图层，也没有新增依赖。
