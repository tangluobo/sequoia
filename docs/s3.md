# S3 与证书存储

## 本轮接入（s3-storage-366）

S3/MinIO 与阿里云 OSS 共用原生存储适配器、后台文件会话和命令总线。原连接中的 endpoint、region、username、password、bucket、s3Prefix、pathStyleAccess、publicAccessUrl 和 SSH 跳板引用继续使用，不转换或重写共享配置。

- 对照 Java S3Service 修正端点规则：无协议的自定义 S3 端点采用 HTTP；空端点按区域构造 AWS 地址。自定义 S3 服务自动采用路径寻址，兼容旧配置中默认 false 的 pathStyleAccess；OSS 继续沿用 HTTPS 默认值。
- 接通 S3/OSS 的 SSH 跳板，覆盖文件会话、连接树、Bucket 枚举、创建/删除、对象读写、跨 Bucket/跨连接复制和证书上传。独立传输适配器在回环 SOCKS 桥与原生 SSH 通道间转发，保留原始 URL、签名 Host 和 TLS 域名验证；域名、IPv4、IPv6 端点使用同一路径。没有关闭证书校验。
- Bucket 列表、目录/对象浏览、三种视图、上传/下载、创建目录、重命名、删除、文本/Markdown/图片预览、外部编辑回传和对象复制继续经过实际存储操作。恢复原 S3/OSS 默认图标视图，沿用原 S3 图标。路径栏获得焦点全选、失焦还原；未提交的输入不修改当前目录，回车仅跳转而不会同时打开所选文件。已有流程的交互与测试见迁移清单；本轮不据此宣称全应用视觉一致。
- 证书窗口可从 S3 或 OSS 连接选择 Bucket，支持刷新、加载状态和错误显示。切换连接清空上一个 Bucket；未保存 Secret Key 时询问临时密钥并继续原请求，后续签发复用本次密钥。默认不写配置；主动勾选保存时仍走 Java 兼容加密仓库、备份与外部修改冲突检查。
- DNS-01 签发、PEM/Nginx/Apache/PFX/JKS/ZIP 导出写入选择的 Bucket 与目录，成功后刷新已经打开的相应文件标签。先校验存储密钥、目录并建立所需隧道，再创建 ACME 订单；取消/失败仍清理本次 TXT 记录。
- 复制操作能够查找仍然存活的 S3 会话中的临时凭据。剪贴板仍只包含连接 ID、Bucket 和对象键；会话关闭即撤销凭据引用。取消复制同时取消尚在建立的存储连接。

## 资源边界

文件和网络请求在后台执行；传输继续流式处理，大对象不整文件装入内存。每个存储适配器最多四个并发请求、每个连接最多缓存四个 Bucket 操作器；每个 SSH 桥最多十六个活动 TCP 流，握手最多十秒，读空闲超时三十秒。代理和 SSH 会话随最后引用释放，凭据索引只保留弱引用，无后台轮询或额外显示缓存。
