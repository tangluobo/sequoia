# 打开表界面对照

原版依据是只读 Java 源码 `TableDataView.java`、`FrozenRowSelectorPane.java` 和
`css/connect-tree.css`。窗口参考由 `crates/core/tests/java/TableDataWindowOracle.java`
直接实例化原控件，注入内存页，并在计划加载任务执行前关闭加载入口；不创建 JDBC
连接、不读取保存主机、不改写旧配置。原版与 Rust 场景均为 896×650、默认 10px 表格字体。

本轮改动：

- 移除打开表中额外的数据/结构切换行及常驻搜索行，恢复事务、文本、筛选、排序、导入、导出的顺序。
- 复用 Java 原 SVG 路径与颜色，按显示缩放缓存六张小纹理。
- 顶部操作栏 35px；表头包含底边框共 29px；数据行 28px；固定选择器 15px。
- 初始列宽使用 `max(UTF-16 字符数 × 8 + 16, 60)`；可拖动列边界调整宽度。
- 白底表格、浅灰表头、网格线、蓝底白字单元格、黑色行指示箭头；空白区不延伸表格网格。
- 固定表头/选择器，横纵滚动采用已有 JavaFX 风格箭头、滑块和翻页交互。
- 底部操作行 27px，右侧首页/上一页/页码/下一页/尾页；SQL 与记录位置独占 21px 状态行。
- 左键表头选择整列，右键表头打开排序菜单；支持单元格/行选择、Ctrl/Shift 多选、拖选、方向键/Tab 和复制。
- SQL 状态复用数据库实际执行的语句生成器，分页和写入仍走原有后台命令。

绘制按可见行、可见列裁剪，不克隆整页数据；选择状态按行使用位图，未选择时不分配单元格空间。
刷新、取消和换页清理选择与焦点；列宽等视图状态不会写入 Java 共享配置。

验证入口：`scripts/qa/table-data.ps1` 生成实际原生窗口的普通/选中截图；
`scripts/qa/compare-table-data.py` 检查区域背景、行距和网格位置。控件回归覆盖点击、复制、
方向键焦点保持、行选择器、换页清理、可见行渲染及紧凑菜单行高。

截图对照范围是初次打开与单单元格选中，不代表所有编辑弹窗、菜单状态或整应用已逐像素一致。
JavaFX 与 egui 的字体光栅化亦分别保留各自渲染路径。全量迁移状态仍见 `migration.md`。
