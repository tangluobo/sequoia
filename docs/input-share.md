# 鼠标和键盘共享（Windows）

从左侧导航的“键鼠”进入。在一台主机点击“启动服务”，其他主机点击“扫描主机”选中地址，或直接填写 `IP:端口`，输入服务端显示的完整配对码后“主动加入”。单节点服务也可以扫描并加入另一服务；已有多人会话时先停止再加入其他组。服务端退出会结束整组共享。

加入后，各主机显示同一横向节点列表。拖动卡片改变顺序，排列由服务端串行同步到所有节点。光标到达左右边缘时转入相邻主机，按两端虚拟桌面尺寸映射纵向位置，键盘、左右/中/侧键、垂直及水平滚轮随之转移。卡片绿色表示当前控制的主机。每台主机使用自身显示器集合的虚拟桌面包围矩形；显示器配置变化会重新发布尺寸并返回本机。

被控端没有连接实体鼠标，或 Windows 隐藏/抑制系统指针时，会自动显示共享指针，随接收到的位置移动。系统指针正常且已接鼠标时继续使用系统指针；本地接管、切换主机、暂停或断开后移除共享指针。共享指针不抢占焦点、不拦截点击，也不修改 Windows 指针设置。

按 **Ctrl+Alt+F12** 返回本机并暂停本节点边缘切换，点击“恢复边缘切换”继续。窗口内也可“返回本机 / 暂停”。被远程控制的节点使用本地实体键鼠时可收回控制权；切换控制源、修改排列、队列拥塞及断线会释放注入的按键和鼠标按钮。系统输入失败或输入队列拥塞时直接结束当前会话，重新启动或加入后继续，避免重放队列中残留的按下事件。关闭共享窗口后服务继续运行；“停止并退出共享”或退出应用释放该会话。

发现使用 UDP 24819；输入流使用 TCP，默认端口 24819。广播发现仅覆盖允许广播的同一局域网，其他网络可手动填写地址。允许 Windows 防火墙的专用网络访问即可，不自动修改防火墙。发现结果尚未认证，建立输入连接时才验证配对码。配对码随机生成、仅在本次服务生命周期有效，不写入配置；所有 TCP 记录通过 HKDF-SHA256 派生连接方向密钥，以 ChaCha20-Poly1305 认证加密，序号拒绝重放。节点上限 16，连接、任务和消息队列有界。此功能不读写 `connections.json`，不启动 Java、PowerShell 或外部键鼠共享程序。

CLI 使用 `tomato-cli input-share` 保持会话，向标准输入逐行提供 Action JSON，例如：

```json
{"Start":{"port":24819}}
"Status"
{"Order":{"ids":["节点ID2","节点ID1"]}}
"Release"
"Resume"
"Stop"
```

也支持 `"Scan"`、`{"Join":{"address":"192.168.1.2:24819","code":"服务端配对码"}}`。每行返回一个 JSON 结果，`Stop` 或标准输入结束后退出。GUI 和 CLI 共用 `Command::InputShare`，CLI 同样受 Windows 输入权限限制。

范围：当前系统适配器仅支持 Windows 交互桌面。Windows 安全桌面、Ctrl+Alt+Delete 和更高权限进程受系统输入权限限制；不包含跨机文件拖拽、剪贴板共享或音视频传输。多显示器空洞按虚拟桌面包围矩形处理。真实多台物理主机、不同 DPI/多显示器组合、中文输入法、管理员程序、游戏及长时间断网恢复仍需实机验收；不能以回环协议测试代替这些验收，也不标记为全部场景完成。

键盘协议区分普通/扩展硬件扫描码和虚拟键码，以覆盖多媒体键、Pause 和 PrintScreen；不把扫描码为零的按键直接丢弃。

验证记录另见 `docs/migration.md`。自动网络检查仅使用动态端口回环夹具，系统输入由 fixture 接收，不安装全局钩子、不移动用户光标。独立的 `tomato-native-input` 示例 `probe` 仅验证钩子启动和释放，不注入输入。最终格式、严格检查、完整回归、正式窗口、内存测量与打包并入 1682 合并交付；真实物理多机验收仍未完成。
