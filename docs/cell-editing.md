# 打开表的单元格编辑

原 Rust 打开表页面仍使用早期的“编辑单元格”浮窗：双击或按编辑键会离开网格，在独立的多行输入框里确认。原 Java `TableDataView.EditableTableCell` 则直接把当前单元格替换为输入框。本轮删除前一条浮窗路径，将真实数据表接入表内编辑。

## 交互

- 悬停不开始编辑；首次按下鼠标即选中，松开只恢复键盘焦点，不重复切换选区。第一次拖选保留起点；Ctrl 点击只切换一次。从其他控件开始的拖动不会变成数据网格选区。再次点击已选中的单元格、双击或使用编辑键，在原单元格内输入并选中原文本。
- Enter 或点击其他单元格/工具栏提交到暂存区；Esc 撤销当前输入，保留此前已经暂存的其他修改。未改内容就退出不会制造未保存标记。
- 保存按钮在当前输入已改变时可用，一次点击先完成单元格输入，再发送原数据库 Apply 命令。编辑时按 Enter 不会直接写数据库；保存失败仍走既有的错误与草稿保留流程。
- 进入编辑和首个文本事件落在同一帧时保留输入；编辑框里的文字拖选不再触发表格范围选择。未编辑时的行/列选择、复制、方向键和多选路径继续保留。
- NULL 显示为空输入，未改内容时保留 SQL NULL；空字符串和字面量 `NULL` 仍分别处理。新增行未输入的 DEFAULT 保持省略列语义，二进制继续按十六进制编辑，SQLite 继续保留原有数值校验。无效输入在状态栏提示并留在原单元格，不弹编辑框。
- 日期、时间和日期时间默认也在单元格里输入；只有点击右侧选择按钮才打开日历/时间选择器。选择器复用查询结果已有的原生控件，返回后继续编辑当前单元格。

输入框使用白底、黑字、2px 蓝色边框、边框内 4px 水平留白和垂直居中文字。只保留一个活动输入缓冲，不复制整页结果；提交时沿用既有的单行暂存。编辑结束、取消、刷新或标签销毁时释放文字撤销状态和选择器；未增加字体文件副本、后台任务或持续刷新。

## 验收

只读编译原 Java 当前 `TableDataView.java` 到本项目 `target/cell-oracle-360/classes`，用合成的 1000 行数据执行原控件的鼠标、F2、Enter、Esc、失焦事件。未修改原 Java 工程，也不连接保存的服务器。原控件事件记录为 `target/cell-oracle-360/editing.png.events.json`；原源码、CSS 和辅助程序哈希见该目录的 `identity.json`。

Rust 回归直接向真实网格与完整表格页面送入指针和键盘事件，验证按下选中与首次拖选、Ctrl 单次切换和键盘焦点恢复、表内编辑、文字对齐、快速输入、文字拖选、NULL/空串/二进制、显式日历按钮、撤销状态释放，以及一次保存点击发出的完整 Apply 命令。默认工作区 415 项测试、严格 Clippy、格式检查、全目标开发构建和 CLI 自检通过，62 项条件测试默认忽略。

开发版三种窗口（普通、选中、编辑）已经对照通过，证据为 `target/window-probes/cell-dev-final-363/geometry.json` 和 `interaction-proof.json`。普通页的原工具栏、网格和选择范围保持；活动输入框的外边界及底色与原控件对应。原 Java 内侧竖边有白色背景抗锯齿混合，字形/文本选区边界仍有约 1–2px 差别；比较器记录这些差异，没有宣称所有文字和边框像素完全一致。

实际 Cargo 优化成品为 `target/qa-release-cell-edit-363/release/tomato.exe`（93,428,736 字节，SHA-256 `B9D72F1A3A9B2AA1CEBF4170F74E03BC32DCC423BB02C86A3D28DDA0F202617E`）。成品普通、选中、编辑三种表格窗口及四种主标签/溢出窗口对照通过，标题栏底线保持；查询结果的日期、时间、日期时间三个共享原生选择器通过隔离 SQLite actor 与窗口检查。测试仍为 415 通过、0 失败、62 条件忽略，未宣称所有选择器交互均已视觉验证。

1455 个运行源文件哈希复核通过，原 Java 参考源码、旧成品和原 exe 六尺寸图标保持。共享旧配置只读检查为 60 个连接、4 个分组，验收前后哈希相同，没有连接保存的主机。完整记录在成品同目录 `build-info.json`，成品表格证据在 `target/window-probes/cell-release-363/`。
