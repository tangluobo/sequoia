# SSH 终端混排与脚本输入

终端按固定列绘制，中文宽字符占两列。用当前字体的典型大写字母和数字的可见字形计算上下居中的基线。普通文字、反白表头、光标内的反色字符和输入法预编辑文字共用这条稳定基线，实时输出时同一行不会随字符变化而上下移动。中文回退字形、组合附加符号和英文字形各按自己的度量落在同一基线上。光标块跟随终端单元格坐标，包括 Shell 提示符自带的尾随空格。绘制复用现有字体和字形缓存。

按原 Java TerminalView 的约定，Backspace 发送 `0x08`，Delete 发送 `ESC [ 3 ~`。SSH 创建 PTY 时声明 `VERASE=8`，使远端的规范行输入使用相同擦除键；原先未声明时，远端可能使用 DEL，导致 shell 的 Readline 能退格而脚本 `read` 无法擦除。输入法删除前文也使用相同退格字节。

编辑由远端程序处理，不在客户端伪造密码回显或缓存输入结果。普通参数输入、关闭回显的密码输入可使用 Backspace；光标移动及向前 Delete 适用于支持行编辑的程序，例如 Bash `read -e`。普通 POSIX `read` 本身不是完整的行编辑器，客户端不会将其自动替换为 Readline。

验证覆盖 Windows 安装字体、四种 DPI、中英文/数字/组合字符及光标的实际绘制几何，以及隔离原生 SSH 上的真实 Bash PTY 参数、隐藏输入和 Readline 编辑。Windows 使用本地 MSYS Bash 和 ConPTY，不能等同于对所有 Linux 脚本或用户保存主机的人工验收；执行结果见发布包验证日志。
