原 Java 只读参照为 `TableStructureView.java:790` 的矩形单元格选择、`:2869` 的行选择器，以及 `RowSelectorDragSelection.java` 的整行拖动。原版支持单元格矩形、行选择器拖动、Ctrl 非连续选择和 Shift 行范围；每个含选中单元格的行都有选择器箭头。

原 Rust 界面在行选择器按下和松开时都调用清空后单选，忽略修饰键且没有建立整行拖动状态。普通单元格的按下处理与松开后的 `clicked` 同时执行，Ctrl 切换会执行两次，造成选中立即被取消。

现在由一个按下入口建立选择，松开仅结束拖动。选择状态和行/单元格两种拖动分别放在 `tabs/table_design/selection.rs`，命中、输入仲裁和边缘滚动放在 `panels/sql/designer/selection.rs`。使用已有的每行八列位图，最多 4096 行约 8 KiB，不复制字段草稿，也不分配逐单元格集合。

- 行选择器普通点击选中整行，Ctrl 追加或取消行，Shift 从当前焦点行选择连续范围；Ctrl+Shift 沿用 Java 的 Ctrl 优先。整行拖动跨入数据单元格后仍然选择整行，反向拖动和缩小范围都即时更新。
- 普通数据单元格可拖动选择矩形，Ctrl 可选非连续单元格，Shift 可从锚点扩展矩形。拖过类型、非空和主键列不会触发编辑或切换值。
- 数据类型仍保留单击打开原类型下拉；已进入文字编辑的单元格保留文字拖选。行选择器和单元格右键保留已有多选，批量复制和删除继续使用同一份选择。
- 选择器箭头按照每行是否有选中单元格绘制。网格行高、列宽、分隔线与提交/取消布局不变。滚轮和滚动条继续工作；从网格发起的拖选在边缘滚动，松开、指针丢失或切换页面后停止。
- 选择仅更新选择位图。删除修改未保存草稿，仍由原来的保存按钮提交数据库；没有自动发送 DDL，也没有改写连接配置。
