# 左侧导航彩色图标

按用户要求，五个主导航入口改用统一的彩色 SVG。连接为蓝色地球、工具为橙色交叉工具、服务器为紫色机架、开发为青绿色代码窗口、设置为蓝灰色齿轮。此次导航图标的颜色和造型属于明确要求的外观调整，不作为原 Java 单色图标的复刻验收。

替换范围仅为 `crates/ui-egui/assets/nav/` 中的五个既有文件。导航栏仍为 62px，图标仍为 24px；原点击区域、悬停背景、工具提示和模块切换逻辑保持不变。SVG 直接嵌入程序，按目标物理像素尺寸渲染，复用有界纹理缓存；不引入新字体、网络资源、运行时依赖或动画刷新。五个 SVG 共 2486 字节，比旧版增加 349 字节；100% DPI 下五张 RGBA 纹理的像素负载仍为 11520 字节，不含缓存对象与驱动开销。

开发构建的连接页和工具页截图与 layout-355 比较，变化仅位于五个图标矩形内，其他像素完全相同。可复查脚本 `scripts/qa/compare-nav.py` 和 `target/window-probes/nav-dev-357/navigation-proof.json`。该对比验证本轮替换的范围，不代表全应用已经完成迁移。

格式、严格 Clippy、全目标开发构建、406 项默认测试、CLI 自检和旧配置只读检查通过，62 项条件测试默认忽略。共享配置保持原文件，读取结果为 59 个连接、5 个分组；检查未连接保存的服务器。
